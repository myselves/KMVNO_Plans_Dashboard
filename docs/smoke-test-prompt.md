# 스모크 테스트 프롬프트

예약 작업을 등록하기 전에 **수집 경로가 살아 있는지만** 빠르게 확인하는 용도다.
전체 갱신(17개 소스)은 오래 걸리므로, 대표 5개 소스로 먼저 검증한다.

선정 기준은 수집 방식이 서로 다른 것들이다. 이 5개가 통과하면 나머지 12개는
같은 방식의 변형이라 통과할 가능성이 높다.

| 소스 | 검증하는 것 |
|---|---|
| 핀다이렉트 | JSON API + 할인액 계산식 |
| 모빙 | JSON API + 총액 필드 계산식 |
| 모요 | 대량 페이지네이션 (①변동감지·⑥·⑦의 원천) |
| U+유모바일 | get_page_text 단순 추출 |
| 쉐이크모바일 | computer 도구 실좌표 클릭 (가장 깨지기 쉬움) |

## 실행 방법

**Claude Desktop 앱에서 일반 세션으로** 실행한다. 예약 작업과 같은 환경
(Cowork 세션 + claude.ai 계정 스킬 + 로컬 Chrome)이라야 의미 있는 테스트가 된다.
터미널 CLI로 돌리면 스킬을 읽는 경로가 달라 예약 작업 환경을 검증하지 못한다.

아래 프롬프트에서 `<저장소 경로>` 만 실제 클론 위치로 바꿔 붙여넣는다.

## 프롬프트

```text
[MVNO 대시보드 — 스모크 테스트 (수집만, 파일 수정 금지)]

작업 폴더: <저장소 경로>

목적: 주간 자동 갱신을 걸기 전에 수집 경로가 살아 있는지만 확인한다.
파일을 절대 수정하지 말고 커밋·푸시도 하지 말 것. 결과만 보고하라.
전량 수집도 하지 말 것 — 아래 지정한 표본만 확인한다.

0. mvno-dashboard-update 스킬이 로드되는지 확인한다. 로드되지 않으면 즉시
   중단하고 "스킬 미로드"라고 보고하라. 스킬의
   references/data-sources.md 를 읽고 아래 수집 방법을 그대로 따른다.

1. /chrome 으로 Claude in Chrome 연결 상태를 확인한다. 미연결이면 중단하고
   보고하라.

2. 핀다이렉트 (data-sources §2)
   z-api 의 deal 목록에서 'Z Speed 150GB+' 프로모션가를 계산한다.
   기대값: 72,600 − 27,700 − 20,900 = 24,000원 (이후 51,700원)

3. 모빙 (data-sources §3)
   getPlanList 에서 '[S] 데이터 11GB+' 의 정가/프로모션가를 계산한다.
   기대값: 49,500 − 3,300 − 36,300 = 9,900원 / 7개월

4. 모요 (data-sources §1)
   1페이지(size=100)만 받아 totalCount 를 확인한다. 전량 수집 금지.
   기대: totalCount 약 2,300건

5. U+유모바일 (data-sources §4)
   요금제 목록 페이지에서 요금제 개수를 센다. 기대: 약 133개

6. 쉐이크모바일 (data-sources §12)
   JS click 이 안 먹는 사이트다. computer 도구로 카테고리 탭 실좌표 클릭이
   되는지, 카드 텍스트가 추출되는지 확인한다. 팝업이 뜨면 먼저 닫는다.

각 항목은 실패해도 중단하지 말고 끝까지 진행한 뒤 종합 보고하라.

보고 형식:
[스모크 테스트 결과]
스킬 로드: O/X
Chrome 연결: O/X
① 핀다이렉트 API: O/X (실측값)
② 모빙 API: O/X (실측값)
③ 모요 스캔: O/X (totalCount)
④ U+유모바일: O/X (요금제 수)
⑤ 쉐이크모바일: O/X (실패 시 원인)
종합 판단: 전체 실행 가능 / 불가 (사유)
```

## 결과 해석

- **전부 O** → `docs/scheduled-task-prompt.md` 로 전체 실행을 한 번 돌린다
- **기대값과 다른 숫자가 나옴** → 사이트가 가격을 바꿨거나 계산식이 바뀐 것이다.
  전체 실행을 돌려도 되지만, 그 브랜드 값은 결과에서 한 번 더 확인한다
- **특정 사이트만 X** → 사이트 개편 가능성. 전체 실행은 진행하되(스킬이 실패
  브랜드는 기존 값을 유지한다) 해당 소스의 수집 방법을 다시 찾아야 한다
- **스킬 미로드 / Chrome 미연결** → 전체 실행 금지. 환경부터 해결한다
